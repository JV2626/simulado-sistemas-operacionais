## 🎯 Conteúdos Abordados:
1. **Tipos de Sistemas Operacionais:** Monoprogramáveis vs Multiprogramáveis (Batch, Tempo Compartilhado, Tempo Real RTOS com Hard vs Soft Deadline).
2. **Múltiplos Processadores:** Sistemas Fortemente Acoplados (SMP / Memória Compartilhada) vs Fracamente Acoplados (Clusters / Beowulf).
3. **Virtualização:** Hypervisors Tipo 1 (Bare-Metal) vs Tipo 2 (Hosted) vs Containers (Docker).
4. **Processos:** Espaço de endereçamento (Text, Data, Heap, Stack), Bloco de Controle do Processo (PCB), Ciclo de Vida dos 5 Estados (Novo, Pronto, Executando, Bloqueado, Terminado) e Troca de Contexto (*Context Switch*).
5. **Threads:** Compartilhamento de memória, contexto exclusivo (TID, PC, Registradores, Stack própria), modelos de mapeamento (1:1, N:1, M:N), concorrência vs paralelismo real, condição de corrida (*Race Condition*) e Mutex.
